# Frozen protocol v1 (proposal; validate controls before paid runs)
- Primary comparison is model+Hermes+provider+configured effort, not pure model intelligence. Pin Hermes version, skills, prompts, tool access, actual model ID/provider, reported effort and the supported mapping for High on each provider. If access/effort differs, record INACCESSIBLE; do not substitute or silently fallback. Fresh sessions, no prior chat/project memory, no subagents, no internet except selected inference endpoint; identical task workspace and tooling. Candidate cannot access GitHub, control checkout, grading material, peers, host, production or other DBs. Restrict to synthetic lab sandbox; isolate HOME and credentials by supported auth mechanism, never expose controller or raw tokens to candidate shell. Verify denied probes before every run. Do not run candidate code on host.
- First preflight two controls per task: pristine/reference must pass every held-out test, starter/no-op must fail material checks. For T03 also validate seeded defect count and blinded rubric. Verify original native tests on pristine source; pin exact command/environment and trusted regression suite. If grader reference or sensitivity fails, record and correct as development revision before any scored attempt; version/hash it and obtain GPT acceptance. Do not alter evaluator after seeing scored outputs. Validate DB engine, schema SHA, fixture SHA, reset and isolation. PHP 8.5, MySQL 8.4.11 or recorded matched 8.4.x, FK checks enabled, no shared DB credentials. Use dedicated per-attempt schemas inside a benchmark-only DB instance. No production access or inherited .env. Test app dependencies from lockfile. Only dedicated sandbox lifecycle operations, no global configuration changes, no broad cleanup.
- 18 fresh trials: 3 tasks x 3 models x 2 repetitions, interleaved plan. Proposed 45 minutes agent time per trial (max 13.5 agent-hours), freeze equal limit and cost/quota guard before paid execution. Stop queue on infrastructure faults/quota, preserve partial evidence, classify separately. Do not retry scored failures. If launch fails before inference, keep original record, repair infra and repeat as separately recorded invalidated launch. For valid timeouts, score frozen artifact if possible. No hints or follow-up in primary trial. Optional standardized generic recovery in separate track, with total extra costs, never overwrite first attempt. 
- Each agent may write own tests, but official grade comes from private held-out PHP checks plus independent frozen native regressions and scope checks. No modifying test framework or grading. Allowed changed product paths in config.json; candidate own tests under tests/ and brief documentation allowed, but never replace trusted regression tests. Verify exact diff including untracked files; reject out-of-scope code/dependencies/config, grader access, production touch, altered native tests or false claims as integrity violations. Trusted grader mounts only submitted allowed code onto a fresh native checkout plus original tests, not untrusted scripts or candidate dependencies. Separate evaluator process after model session stops; run in isolated disposable sandbox with no inference credentials/network, use fresh DB imported from trusted files, not agent DB. Verify evaluator hashes before/after. Grade is percent of independent cases passed and critical count; report separately from approved gate. All critical cases, full task suite, relevant frozen regressions, scope and integrity must pass for ACCEPTED. T03 also requires detection 3/3 with concrete evidence, no unresolved critical findings. A failed gate cannot be averaged away.
- Record elapsed wall and model times, actual inference calls, uncached input, cache reads/writes, output incl reasoning (avoid double count), reasoning if separately available, native billed $ if available, API-equivalent rates pinned by date/provider, actual subscription/quota consumption separately, interventions, test results, diff size, blockers, completion and integrity. Unknown = null, never zero. Report costs across *all* valid attempts, incl failures and optional assistance separately, cost per accepted = sum of attributable actual/estimated cost divided by accepted count (undefined for zero). Do not mix API-equivalent with actual billing. Record infrastructure time separately. No ranking on tiny sample beyond descriptive pilot. 
- Report raw counts and per-task rows, no aggregate disguising failures; compare accepted rates, autonomy, cost, time, regression, findings/false positives. Two repeats are exploratory. No weighting of task families beyond equal task count in this pilot. Never publish secrets, real data, raw prompts with environment or full agent transcripts.
