Return a list of ints, one per input in input order, including duplicates; empty => []. For each exact triple, match saldoBaixaDaLinha semantics on the current native schema, never include unrelated movement types; nonexisting => 0; clamp negative outstanding to zero. No writes. For a valid nonempty batch use no more than three database queries total including metadata, regardless of batch length. Preserve existing method and legacy behavior.
