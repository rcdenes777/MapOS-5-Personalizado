# T03 — Independent maintenance audit
You inherit a native MapOS checkout after several teammate changes. Review the stock movement/reconciliation, delivery document and financial receipt models before approving the change for laboratory use. Evaluate correctness, data isolation, security and preservation of valid flows. Do not assume that existing tests prove all requirements. Discover concrete issues independently. Write REVIEW.md with each confirmed finding (file/function, impact, reproduction, expected/observed behavior, proposed minimal fix) and distinguish hypotheses from confirmed bugs. Then apply minimal corrections to the three models where justified and run relevant regression tests. Do not change requirements, schema or unrelated code. Do not access production or any other checkout. Report remaining risks and whether ready for approval.
